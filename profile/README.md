Applied AI engineering from Alicante, Spain. Three engineers building reviewable workflows for documents, knowledge, vision and speech.

## Selected demonstrations

- [Heritage Atlas](https://quarkeon-website.pages.dev/en/projects/heritage-atlas/): interactive photo matching for El Pilar, Notre-Dame and the Alhambra, plus a real sparse reconstruction of El Pilar. [Try the browser demo](https://quarkeon-website.pages.dev/demos/heritage-atlas/en/).

- [Line Inspector](https://quarkeon-website.pages.dev/en/projects/line-inspector/): industrial anomaly inspection with real PCB images, held-out evaluation and human corrections.
- [Perspective Match](https://quarkeon-website.pages.dev/en/projects/perspective-match/): keypoint matching, image alignment and localized visual differences.
- [Scan Delta](https://quarkeon-website.pages.dev/en/projects/scan-delta/): 3D scan registration and added/removed geometry inspection.
- [Scene Foundry](https://quarkeon-website.pages.dev/en/projects/scene-foundry/): real photographs, estimated cameras and navigable sparse reconstruction.
- [Document Relay](https://quarkeon-website.pages.dev/en/projects/document-relay/): OCR, human approval and delivery to a separate persistent HTTP ledger.
- [Knowledge Atlas](https://quarkeon-website.pages.dev/en/projects/knowledge-atlas/): document questions, source citations and explicit abstention.

[See all seventeen demonstrations](https://quarkeon-website.pages.dev/en/projects/). Each case includes a video, a case-study PDF and recorded evaluation limits. Data sources are identified per case: public real-world datasets, licensed photographs or controlled fictional fixtures. These independent demonstrations report measured results within their stated scope.

## Working together

Validate a use case → build an evaluated pilot → integrate into an agreed workflow. We define scope, milestones and acceptance checks before implementation. Maintenance is scoped separately.

We follow relevant model releases and compare quality, speed, cost and resources before adopting changes. Our applications evolve according to practical value and project requirements.
